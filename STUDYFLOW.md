# StudyFlow

A fully customisable study-time tracker for Android, built with Kotlin and Jetpack Compose (Material 3).

## Open and run
1. Install Android Studio (Koala or newer) and open this folder.
2. Let Gradle sync (it will download Gradle 8.7 and the Android SDK 34 pieces it needs).
3. Press Run on a phone or emulator (Android 8.0 / API 26 or newer).

To get an installable APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

## Features
- Stopwatch and Pomodoro timers that keep counting when the app is in the background
- End-of-phase notification and vibration (Pomodoro)
- Subjects with emoji, colour, per-subject daily goals, archiving
- Session log with manual entry, notes and delete
- Stats: today / week / streak, 7 and 30 day charts, per-subject breakdown, daily and weekly goals
- Backup and restore (JSON) and CSV export

## Everything is customisable (Settings tab)
- Theme: system / light / dark, dynamic colour, pure-black mode, any accent colour (palette or hex)
- Text size, corner roundness, timer ring thickness, ring colour mode
- Focus, short break, long break, rounds, auto-start, minimum session length
- Daily and weekly goals
- Vibration, notifications, keep-screen-on, ask-for-note, seconds, 12/24h, first day of week
- Show or hide the Log and Stats tabs
